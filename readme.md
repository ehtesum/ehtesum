## Featured Project

### [5G NR PDCP Reordering Engine (5G_reorder)](https://github.com/ehtesum/5G_reorder)
A lightweight C++17 user-space networking daemon implementing 3GPP TS 38.323 packet sequence reordering over UDP. Decouples asynchronous UDP socket ingestion from reordering logic via a bounded thread-safe queue (`std::mutex` + `std::condition_variable`), buffering out-of-order packets and resolving sequence gaps using sliding-window tracking and a `t-Reordering` timer flush.
